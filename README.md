# Image Generator Project

This project demonstrates how to generate realistic images from text prompts using a deep learning model in **Google Colab**.  
It was created as a mini project to explore AI-based image synthesis.



## Features
- Generates unique images from user-provided text descriptions  
- Runs entirely on Google Colab (no local setup needed)  
- Uses Python and machine-learning libraries for image generation  
- Saves or displays generated images directly in the notebook
